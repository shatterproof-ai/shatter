## Purpose

Umbrella for bento-side issues found by the shatter audit of 2026-09-22. That audit read shatter session transcripts (2026-09-05 to 09-22) and live repo state, and ran bento scripts read-only against shatter. It found several bento-rdtn fixes (the 2026-09-04 audit follow-ups) that pass bento's single-session fixtures but fail under shatter's real conditions:

- many concurrent sessions
- one shared primary checkout, with all work in linked worktrees
- beads git hooks that take about 300 s

## Shared root causes

1. No test harness runs bento under consumer conditions: concurrency, linked worktrees, slow hooks.
2. rdtn children were closed when their code merged, not when the symptom disappeared.
3. Warnings are emitted with no remediation path (doctor "let closure clean it up" when closure has no such mode).
4. Guidance that spans repos has no contract checks.
