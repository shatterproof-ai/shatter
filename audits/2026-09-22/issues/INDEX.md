# Audit 2026-09-22: reconciled issue set (index)

Nothing is filed yet. This index covers every draft under `issues/<repo>/<bucket>/`. The maintainer files them with **one** script, [`file-all.sh`](file-all.sh) (D6). Old per-set `drafts/*/file.sh` scripts are superseded and exit 1.

```
DRY_RUN=1 bash issues/file-all.sh                 # default: print every command, write nothing
APPLY=1 ONLY=shatter bash issues/file-all.sh      # file one repo section (asks to confirm)
APPLY=1 ALLOW_UNREVIEWED=1 bash issues/file-all.sh  # also file buckets with no cross-check verdict
```

The filer writes a ledger (`filed-ledger.tsv`, slug to id) and skips anything already in it, so it is safe to re-run after a partial failure or after lifting a hold. Its latest dry run is in [`file-all.dryrun.txt`](file-all.dryrun.txt). By default it **holds** the 4 slugs with a BLOCKER finding and the 5 buckets whose cross-check produced no verdict. Everything else is filed as drafted, **including drafts with MAJOR findings**, so fix or `HOLD=` those first (see below).
