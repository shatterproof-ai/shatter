Manage anonymous usage telemetry

Usage: shatter telemetry [OPTIONS] <COMMAND>

Commands:
  status    Show telemetry consent state, config location, and queue info
  off       Disable anonymous telemetry
  on        Enable anonymous telemetry
  reset-id  Regenerate the anonymous ID
  help      Print this message or the help of the given subcommand(s)

Options:
      --log-level <LOG_LEVEL>
          Log verbosity level: error, warn, info (default), debug, trace
          
          [default: info]

  -v, --verbose...
          Increase verbosity (-v = debug, -vv = trace)

  -q, --quiet
          Decrease verbosity to warnings and errors only

      --project-dir <DIR>
          Override auto-detected project root directory

      --color <WHEN>
          When to use terminal colors: always, auto (default), or never. Respects the NO_COLOR environment variable (auto treats it as never)
          
          [default: auto]
          [possible values: always, auto, never]

      --render <MODE>
          Terminal rendering mode: md (default, rendered via termimad) or plain (legacy ANSI)

          Possible values:
          - md:    Markdown rendered via termimad (default). Use `--color never` for raw Markdown
          - plain: Legacy plain ANSI text output (deprecated)
          
          [default: md]

  -h, --help
          Print help (see a summary with '-h')
