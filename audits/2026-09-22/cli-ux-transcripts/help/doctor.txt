Diagnose the local Shatter install.

Reports the embedded frontend hashes and, in a source checkout, whether the embedded Go frontend is stale relative to the current `shatter-go/` sources (str-o09e). Also checks the target project for any configured output path (cache, seeds, artifacts, report) that its `.gitignore` fails to cover (str-1fwt). Exits non-zero if a stale embed or an un-ignored generated path is detected.

Usage: shatter doctor [OPTIONS]

Options:
  -d, --directory <DIRECTORY>
          Project directory to check for un-ignored generated paths (default: auto-detected project root)

      --log-level <LOG_LEVEL>
          Log verbosity level: error, warn, info (default), debug, trace
          
          [default: info]

  -v, --verbose...
          Increase verbosity (-v = debug, -vv = trace)

  -q, --quiet
          Decrease verbosity to warnings and errors only

      --project-dir <DIR>
          Override auto-detected project root directory

      --color <WHEN>
          When to use terminal colors: always, auto (default), or never. Respects the NO_COLOR environment variable (auto treats it as never)
          
          [default: auto]
          [possible values: always, auto, never]

      --render <MODE>
          Terminal rendering mode: md (default, rendered via termimad) or plain (legacy ANSI)

          Possible values:
          - md:    Markdown rendered via termimad (default). Use `--color never` for raw Markdown
          - plain: Legacy plain ANSI text output (deprecated)
          
          [default: md]

  -h, --help
          Print help (see a summary with '-h')
